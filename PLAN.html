Goals

  • Fun firstIt should feel like a game, not a worksheet with graphics added on top.
  • Learning in the gameThe questions are part of how you play (shoot the right answer, build a bridge with the right word), not quizzes between levels.
  • One HTML file per gameDouble-click to open it in any browser. No install and no server, and it works offline once loaded.
  • Short sessionsOne round takes 5–10 minutes.
  • Grade 1 first (Nov 2026)Class 1, CBSE / NCERT. Other grades welcome (see CONTRIBUTING.md).
  • Linked to the syllabusUse topics children are studying in school: Maths, English, Science, Hindi, General.

Ground rules for every game

Format
One .html file. three.js from a CDN with a fixed version (e.g. three@0.160.0)
Controls
Mouse/touch first, so it also works on a tablet or phone. Keyboard is optional
Questions
Kept in a plain array at the top of the file, so anyone can change them without touching game code
Difficulty
Easy / Medium / Hard picker, or it gets harder slowly as the child plays
Feedback
Show the right answer kindly when the answer is wrong. Never just "WRONG"
Rewards
Stars, points, unlockable colours/characters. Best score saved in localStorage
Sound
Simple effects, with a mute button
Language
Simple English on screen. Hindi games use Devanagari

    Play Web link (any phone)
  • Pizza Party✓ Built

    Picnic pizzas with animal friends. Equal and unequal parts, halves, quarters, sharing toppings equally, "half of 8". Replaces the Fraction Pizza idea at Class 1 level.

    Play Web link (any phone)
  • Shape Hunter✓ Built

    Find things on a picnic blanket: shaped like a ball, box, can or cone, then sphere / cube / cuboid / cylinder / cone, then which shapes roll, stack or have a circle face.

    Play Web link (any phone)

    A toy-and-snack shop. Know the ₹1, ₹2, ₹5, ₹10 coins, count money, pay the exact price coin by coin, "can I buy it?", which costs more, change from ₹10/₹20/₹50.

    Play Web link (any phone)

How to start a new game

  1. Clone the repo (or fork it on GitHub).
  2. Pick one idea from the list above (or a new one) and decide:
    • the subject and the exact topic (e.g. "6 and 7 times tables")
    • the game idea
    • the class / level it is for
    • that it follows the ground rules above and in CONTRIBUTING.md
  3. Save it in the repo under grade-1/<subject>/ with a lowercase hyphenated name, e.g. grade-1/maths/number-blaster.html, add its card to grade-1/index.html and the README table, then open a pull request (or commit and push if you maintain the repo).
  4. Play-test it with a child, write down what they liked or found boring, and adjust.
  5. Tick it off in the plan and add a row to the progress log.
